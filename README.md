# Сайт кафедры ВТИСиТ

## Локальный запуск

Скопируйте `.env.example` в `.env` и задайте `JWT_SECRET` значением из `openssl rand -hex 32`.
Затем запустите приложение и откройте [http://localhost:8080](http://localhost:8080).

```sh
docker compose up --build -d
```

Для развёртывания под HTTPS укажите `AUTH_COOKIE_SECURE=true` и задайте публичный
адрес сайта в `AUTH_ORIGIN`, например `https://itis.example.org`.

## Роли и доступ

Публичная регистрация отключена. Неавторизованный посетитель имеет доступ к главной, новостям и списку преподавателей с публичными карточками. Студент и преподаватель также видят личный кабинет. Администратор дополнительно управляет новостями, преподавателями и ролями. Существующий аккаунт с ролью guest сохраняет публичные права и может выйти из аккаунта.

Создание аккаунтов через локальную команду (пароль вводится интерактивно):

```sh
docker compose exec app python -m api.app.manage_auth admin --create --role admin
docker compose exec app python -m api.app.manage_auth student01 --create --role student
docker compose exec app python -m api.app.manage_auth teacher01 --create --role teacher
```

Для изменения роли существующего аккаунта уберите `--create`. Администратор также может менять роли пользователей через интерфейс.

Расписание будет добавлено отдельно; существующая схема БД не изменена. Изображение главной — временный фрагмент предоставленного референса, его можно заменить оригинальной фотографией в `frontend/images/campus-reference.jpg`.

В архив не включён `.git` и `api/app/core/.env`: используйте свой локальный репозиторий и настройки окружения. Не удаляйте volume PostgreSQL при обновлении.
