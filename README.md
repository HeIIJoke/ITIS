api/ - Папка для реализацией api
    requirements.txt хранит список необходимых библиотек
frontend/
    css/
        components/ - css для компонентов (кнопки, поля ввода и т.д.)
        pages/ - css для страниц сайта
    js/
        pages/ - js файлы для страниц сайта
        router.js - файл с реализацией навигации между страницами
        main.js - файл для реализации общей логики (не связанной с какой-то страницой)
    pages/ - файлы с разметкой html для каждой страницы
        index.html - общая структура сайта: шапка, навигацонное меню, область для отображения содержимого страниц и подвал
run.bat - прописать в консоли папки ITIS. Запускает локальный сервер
