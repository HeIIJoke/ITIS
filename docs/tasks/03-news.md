# Задача 03. Новости кафедры (CRUD)

**Ветка:** `feature/news` · **Зависимости:** нет (позже свяжется с задачей 06 auth)
**Инструменты:** FastAPI, Pydantic, pytest, fetch/JS

## Чему учимся
Полный CRUD: создание, чтение, пагинация, удаление. Коды ответов (201/204/404/422),
тестирование изменяющего состояние API, работа с формой на клиенте.

## Контракт API
| Метод | Путь | Код | Описание |
|---|---|---|---|
| GET | `/api/news` | 200 | список, `?limit=&offset=` (по умолчанию 10), новые сначала |
| GET | `/api/news/{news_id}` | 200 / 404 | одна новость |
| POST | `/api/news` | 201 / 422 | создать `{title, content, author?}` |
| DELETE | `/api/news/{news_id}` | 204 / 404 | удалить |

## План работы
1. Схемы `api/app/schemas/news.py`: `NewsCreate` (вход), `News` (выход, с `id`, `created_at`).
2. Хранилище: **в памяти** (список в модуле сервиса) — БД будет в задаче 05.
   Обязательно `id` автоинкрементом и `created_at` в UTC.
3. Сервис `services/news.py`: `list_news(limit, offset)`, `get_news`, `create_news`, `delete_news`.
4. Роуты + тесты `tests/test_news.py`:
   * создали → `201` и новость есть в списке;
   * пустой `title` → `422`;
   * несуществующий `id` → `404`;
   * сортировка «новые сверху»;
   * `limit`/`offset` реально режут список.
5. Фронтенд `frontend/pages/news.html` + `frontend/js/pages/news.js`:
   форма уже свёрстана (`#news-form`, `#news-container`) — осталось подключить.
6. **Важно (интеграция):** в задаче 06 появится админ-доступ — `POST`/`DELETE`
   должны будут требовать токен. Уже сейчас вынеси проверку в отдельную зависимость,
   чтобы потом добавить одну строчку.

## Подсказки
* `status_code=201` ставится в декораторе `@router.post(..., status_code=201)`.
* Порядок роутов: `/{news_id}` после `""` не обязателен, но следи за конфликтами.
* Экранируй HTML при выводе новости (`textContent`, а не `innerHTML`) — это XSS.

## Definition of Done
- [ ] CRUD работает, коды ответов корректные
- [ ] Тесты покрывают создание/валидацию/404/пагинацию
- [ ] На странице можно опубликовать и увидеть новость без перезагрузки
