# Задача 06. Аутентификация и админ-панель

**Ветка:** `feature/auth` · **Зависимости:** 03 (новости), 05 (БД, желательно)
**Инструменты:** FastAPI Security, JWT или сессии, хеширование паролей, pytest

## Чему учимся
Закрывать изменяющие эндпоинты, работать с `Depends`, ролями и токенами,
тестировать защищённые ручки (401/403), никогда не хранить пароли в открытом виде.

## Контракт API
| Метод | Путь | Код | Описание |
|---|---|---|---|
| POST | `/api/auth/login` | 200 / 401 | `{username, password}` → `{access_token}` |
| GET | `/api/auth/me` | 200 / 401 | текущий пользователь |
| POST | `/api/news` | 201 / 401 | теперь только для `admin` |
| DELETE | `/api/news/{id}` | 204 / 401 | только для `admin` |

## План работы
1. Зависимости: `passlib[bcrypt]`, `pyjwt` (или `itsdangerous` для cookie-сессий).
2. `api/app/core/security.py`: хеш пароля, создание и проверка JWT (`exp` обязателен).
3. `api/app/api/deps.py`: `get_current_user()` и `require_role("admin")` — 
   обычные зависимости FastAPI, подключаются к роутам через `Depends`.
4. `api/app/services/users.py`: пользователи (пока в JSON/БД), пароль — только хеш.
5. Закрыть `POST`/`DELETE` новостей: `dependencies=[Depends(require_role("admin"))]`.
6. Тесты `tests/test_auth.py`:
   * верный пароль → 200 и токен;
   * неверный пароль → 401;
   * запрос без токена к закрытому роуту → 401;
   * токен обычного пользователя к админскому роуту → 403;
   * просроченный токен → 401.
7. Фронтенд: форма входа, хранение токена (`localStorage`), подстановка заголовка
   `Authorization` в `apiGet`/`apiPost` внутри `frontend/js/main.js`.

## Подсказки
* Секрет для подписи — только из env: `JWT_SECRET`. В репозиторий не попадает никогда.
* Пароли демо-пользователей для dev — из env, не из кода.
* `HTTPBearer`/`OAuth2PasswordBearer` даёт бесплатный Swagger-интерфейс для теста руками.

## Definition of Done
- [ ] Логин работает, закрытые ручки отдают 401/403
- [ ] Пароли хранятся только в виде хеша
- [ ] Тесты покрывают успех, 401, 403 и истёкший токен
- [ ] Секрет берётся из окружения, в git — только пример `.env.example`
